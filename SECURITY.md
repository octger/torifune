# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not publish suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository and include:

- affected Torifune version
- reproduction steps or proof of concept
- expected impact
- suggested mitigation, if known

Please do not include authentication cookies, private URLs, downloaded media, or other personal data. Acknowledgement and remediation timing depend on severity and reproducibility.

Torifune downloads yt-dlp and FFmpeg only after explicit user consent and verifies official SHA-256 checksums. Reports concerning those upstream projects should also be sent to their respective maintainers.
